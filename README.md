# Portfólio · Suzane Luz

Meu site pessoal de portfólio, com informações sobre mim, minhas skills, meus projetos e minhas experiências.

🔗 **Acesse:** [suzaneluzz.github.io](https://suzaneluzz.github.io/portf-lio/)

## Seções

- **Início:** apresentação e links para GitHub e LinkedIn
- **Sobre mim:** formação e objetivos
- **Skills:** tecnologias que utilizo
- **Portfólio:** projetos com links para o repositório e para a versão online
- **Experiência:** trajetória acadêmica e profissional
- **Contato:** e-mail com botão de copiar

## Tecnologias

- HTML
- CSS
- JavaScript

O site é uma página única, responsiva (funciona no computador e no celular) e não depende de bibliotecas externas.

## Como rodar

Baixe o arquivo `index.html` e abra no navegador. Não precisa instalar nada.
